プライバシー通知

最終更新日：2026年11月9日

本通知は、サイト閲覧、お問い合わせ、ご注文の際に、keeper.dayとMeetu Studioが情報をどのように取り扱うかを説明します。

1. 取得する情報

ご注文時、Stripeはメール、氏名、請求先・配送先住所、配達用電話番号、決済情報を取得します。当方は注文管理に必要な支払状況、金額、通貨、領収書番号、配送情報、カードブランド・下4桁などの限定的な決済方法情報にアクセスできます。当サイトを通じてカードのセキュリティコードや番号の全桁を受け取ることはありません。

メールやチャットでご連絡いただくと、お客様が提供した連絡先、メッセージ、添付ファイルを受け取ります。ご依頼への対応に必要な情報のみをお送りください。

当サイトとサービス提供者は、IPアドレス、ブラウザー・端末の種類、おおよその位置、参照元、閲覧ページ、操作などの技術・利用情報を受け取る場合があります。

2. 情報の利用目的

注文・連絡先情報を使い、決済、注文管理、配送手配、領収書・注文更新の送信、サポート、キャンセル・返品対応、不正防止、必要な業務記録の保存を行います。利用情報は訪問状況の把握とサイト改善に役立てます。

購入ボタンのクリックを記録する場合があります。クリックやサイトへの再訪は購入完了とはみなさず、支払状況はStripeの記録を基準とします。

3. 当サイトで利用するサービス

  • Stripe 決済ページを提供し、支払・返金処理、注文情報の保存、決済連絡を行います。同社のプライバシー方針も適用されます。 Stripe プライバシーポリシー.
  • HubSpot チャットや連絡ツールを提供します。会話の維持やメッセージと連絡先情報の関連付けに、Cookieや識別子を使う場合があります。 HubSpot プライバシーポリシー.
  • Google Analytics 訪問と操作を測定します。 Google プライバシーポリシー.
  • Meta Pixel ページの訪問を測定し、広告効果の測定とオーディエンス機能を提供します。 Meta プライバシーポリシー.
  • Microsoft Clarity 操作分析、ヒートマップ、セッションリプレイを通じ、ページの利用状況の把握を支援します。 Microsoft プライバシーステートメント.
  • GitHub Pages 静的サイトをホスティングし、運用・安全確保のため技術的なリクエストログを処理する場合があります。 GitHub プライバシーステートメント.

決済情報はStripeのドメインで入力します。当サイトの解析スクリプトはStripeの決済ページでは動作しません。配送時は、必要な配送先・連絡先情報を配送事業者と共有します。

4. Cookie とお客様の選択

「任意のサービスを許可」を選ぶまで、Google Analytics、Meta Pixel、Microsoft Clarity、HubSpotのスクリプトは読み込みません。「必須サービスのみ」でも、お買い物、メールサポート、安全なStripe決済を利用できます。選択はブラウザーのローカルストレージに最長180日保存します。フッターの「Cookie 設定」でいつでも変更できます。同意を撤回すると任意サービスなしで再読み込みし、ブラウザーが許可する範囲で当サイトの既知の任意のファーストパーティCookieを削除します。第三者は自社の方針に従い、収集済みデータを保持する場合があります。Stripeには独自のプライバシー・Cookie設定が適用されます。ブラウザー設定でCookieをブロック・削除したり、提供元のオプトアウト機能を利用したりすることもできます。

選んだ言語をブラウザーのローカルストレージに保存し、次回以降の表示に利用します。この表示設定によって任意の解析・広告・チャットが有効になることはありません。言語はいつでも変更でき、当サイトのストレージを消去すると設定を削除できます。

チャットをご希望でない場合はメールをご利用ください。注文、配送、返金、重要な製品更新の連絡は、ご購入の管理に必要なサービス通知です。

5. 保持・アクセス・セキュリティ

注文の履行、ご依頼の解決、会計・法定記録の義務に必要な期間、注文・サポート情報を保持します。サービス提供者は自社の方針に従って記録を保持します。情報はお住まいの国以外で処理される場合があります。

個人情報の開示、訂正、削除をご希望の場合は、次の宛先へメールをお送りください： support@keeper.day。ご本人確認をお願いする場合や、既存の注文または法的義務のため一部の記録を保持する場合があります。決済に関する機密情報は送らないでください。

6. お問い合わせと更新

プライバシーについては、Meetu Studio までご連絡ください： support@keeper.day または ウェブサイトのチャット。本通知を変更した際は、このページの日付を更新します。
