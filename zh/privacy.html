隐私说明

最后更新：2026 年 11 月 9 日

本说明介绍您浏览网站、联系我们或下单时，keeper.day 与 Meetu Studio 如何处理信息。

1. 我们接收的信息

下单时，Stripe 收集邮箱、姓名、账单与配送地址、联系电话及付款信息。我们可以访问管理订单所需的信息，包括付款状态、金额、币种、收据编号、配送详情和有限的付款方式信息，如卡品牌及后四位。我们不会通过本站接收卡片安全码或完整卡号。

您通过邮件或聊天联系我们时，我们接收您主动提供的联系信息、消息和附件。请仅分享处理请求所需的信息。

本站及服务商可能接收 IP 地址、浏览器与设备类型、大致位置、来源页面、浏览页面和交互等技术及使用信息。

2. 信息的使用方式

我们使用订单和联系信息处理付款、管理订单、安排配送、发送收据与订单更新、提供支持、处理取消和退货、防范欺诈并保存必要业务记录。使用信息帮助我们了解访问并改进网站。

我们可能记录购买按钮的点击。点击或返回网站不视为已确认销售，订单付款状态以 Stripe 记录为准。

3. 网站使用的服务

  • Stripe 托管结账、处理付款和退款、保存订单信息并发送付款通知，同时适用其自身隐私政策。 Stripe 隐私政策.
  • HubSpot 提供网站聊天与联系工具，可能使用 Cookie 或标识符维持会话，并将消息关联至您的联系信息。 HubSpot 隐私政策.
  • Google Analytics 衡量访问与交互。 Google 隐私政策.
  • Meta Pixel 衡量页面访问，并提供广告效果与受众工具。 Meta 隐私政策.
  • Microsoft Clarity 通过交互分析、热图和会话回放，帮助我们了解页面使用情况。 Microsoft 隐私声明.
  • GitHub Pages 托管静态网站，并可能为运营和保护托管服务而处理技术请求日志。 GitHub 隐私声明.

付款信息在 Stripe 域名下输入。本站统计脚本不在 Stripe 托管的结账页运行。履约时，我们向配送服务商提供必要的配送与联系信息。

4. Cookie 与您的选择

您选择“允许可选服务”前，Google Analytics、Meta Pixel、Microsoft Clarity 和 HubSpot 脚本保持关闭。“仅必要服务”允许购物、邮件支持和安全 Stripe 结账，不加载这些可选服务。我们在浏览器本地存储中保存选择，最长 180 天。您可随时通过页脚的“Cookie 设置”更改。撤回同意后，页面重新加载并停用可选服务，在浏览器允许时删除本站已知的第一方可选 Cookie；第三方服务可能依其政策保留先前收集的数据。Stripe 使用自己的结账隐私与 Cookie 控制。您也可通过浏览器设置阻止或删除 Cookie，并使用服务商的退出工具。

我们也会在浏览器本地存储中保存您选择的语言，供以后访问使用。这项界面偏好不会启用可选的统计、广告或聊天服务。您可随时更改语言，也可清除本站存储以移除该偏好。

如果不想使用在线聊天，您可以发邮件联系我们。订单、配送、退款及重要产品更新邮件属于管理购买所需的服务通知。

5. 保存、访问与安全

我们在履行订单、解决请求以及满足会计或法定留存义务所需的期限内保留订单和客服信息。服务商按其政策保存记录，信息可能在您居住地以外的国家处理。

您可通过以下邮箱申请访问、更正或删除个人信息： support@keeper.day。我们可能需要核实您的身份，也可能因现有订单或法律义务保留部分记录。请勿向我们发送敏感付款凭据。

6. 联系与更新

隐私问题，请联系 Meetu Studio： support@keeper.day 或通过 在线聊天。隐私说明发生变化时，我们会更新本页日期。
